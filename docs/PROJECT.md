# Tsumugi Project

## Project Philosophy Document

Version: 0.1

---

# 1. Project Overview

Tsumugi is a personal AI memory platform designed to transform a user's daily experiences, thoughts, emotions, and ideas into a reusable knowledge asset.

The purpose of Tsumugi is not simply to create digital diaries.

The purpose is:

> Transform personal experiences into knowledge that enables future creation.

---

# 2. Core Vision

## "Talk. Connect. Create."

Every conversation creates a new piece of personal knowledge.

Every memory has the potential to connect with another memory.

Every connection has the potential to create something new.

---

# 3. The Problem We Solve

Humans accumulate enormous amounts of valuable information throughout life.

Examples:

- Experiences
- Lessons learned
- Emotional patterns
- Personal preferences
- Ideas
- Goals
- Relationships

However, most of this information disappears because:

- People forget.
- Notes become fragmented.
- Ideas are not connected.
- Past experiences cannot easily be retrieved.

Traditional note apps store information.

Tsumugi builds relationships between information.

---

# 4. Product Definition

Tsumugi is:

"An AI companion that helps users understand themselves and create from their own accumulated experiences."

---

Tsumugi is NOT:

- A simple diary application.
- A chatbot wrapper.
- A note-taking replacement.
- A social network.

---

# 5. Core Concept

## Memory Assetization

The fundamental concept of Tsumugi is:

## Turning memories into assets.

A memory itself has limited value.

A connected memory has much greater value.

Example:

A single note:

"Started tracking my weight."

Another note:

"AI conversations motivated me."

Another note:

"Interested in personal growth."

When connected:

"An idea for a personal AI growth assistant emerges."

The value comes from connection.

---

# 6. User Experience Principle

Users should not feel that they are "managing data."

Users should feel that they are:

- Talking
- Thinking
- Reflecting
- Discovering

The AI handles organization.

The user focuses on expression.

---

# 7. AI Role Definition

The AI in Tsumugi is not:

- A search engine
- A replacement for human thinking
- An authority that gives final answers

The AI is:

## A librarian of personal experience.

The AI helps users:

- Remember
- Connect
- Reflect
- Discover

---

# 8. Memory Model

Tsumugi treats memories as connected objects.

Each memory may contain:

- Timestamp
- Content
- Summary
- Keywords
- People
- Emotions
- Themes
- Related memories
- User goals

---

Example:

Memory:

"I talked with my friend about changing jobs."

Generated metadata:

People:
- Friend

Theme:
- Career
- Change

Emotion:
- Anxiety
- Hope

Related:
- Previous career discussions
- Future goals

---

# 9. Long-Term Value

The value of Tsumugi increases over time.

Day 1:

The user has a diary.

Year 3:

The user has a personal knowledge system.

Year 10:

The user has a searchable archive of their life.

---

# 10. Product Principles

## Principle 1

## User owns the memory.

Personal data belongs to the user.

---

## Principle 2

## Local first.

Whenever possible:

- Store locally.
- Avoid unnecessary servers.
- Keep data portable.

---

## Principle 3

## AI should enhance memory, not replace it.

The AI does not create a fake personality.

It helps users understand their own history.

---

## Principle 4

## Reduce input friction.

Writing a diary every day is difficult.

Conversation is natural.

The main input method should be conversation.

---

## Principle 5

## Connection is more valuable than storage.

A large database is not the goal.

Meaningful relationships between memories are the goal.

---

# 11. Development Decision Rules

When adding a feature, ask:

Question 1:

Does this increase the value of accumulated memories?

Question 2:

Does this help users discover something about themselves?

Question 3:

Does this help future creation?

If the answer is no, reconsider the feature.

---

# 12. Initial Target Users

Primary:

- AI users
- Creators
- Entrepreneurs
- Knowledge workers
- Personal development enthusiasts
- Obsidian users

Secondary:

- Anyone who wants deeper self-reflection

---

# 13. First Product Goal

Do not aim for feature completeness.

The first goal:

Create a magical moment.

Example:

A user asks:

"Help me think about my next idea."

The AI responds:

"Three years ago, you wrote something similar..."

The user thinks:

"Wow. This AI remembers my journey."

That moment defines the product.

---

# 14. Success Metric

The most important metric is:

Not downloads.

Not screen time.

Not messages.

The key metric:

## "Does the user feel that their accumulated memories become more valuable over time?"

---

# Final Statement

Tsumugi is not a tool for recording life.

It is a tool for discovering what life has already taught you.

The past is not just history.

The past is material for the future.
