# Tsumugi

> **過去が、未来を育てる。**
>
> **話すたびに、人生がつながる。**

Tsumugiは、**Personal Memory OS**です。

日記アプリでも、
AIチャットでも、
メモアプリでもありません。

あなたの人生にある会話・経験・感情・アイデアを、
未来の創造につながる「記憶」として育てるためのプロダクトです。

---

# Philosophy

私たちは、記憶を「保存するもの」とは考えません。

記憶は、

**未来の自分と対話するためのもの**です。

今日の何気ない会話。

思いついたアイデア。

悩み。

嬉しかった出来事。

それらは単独では小さな点かもしれません。

しかし時間が経ち、
別の経験と結び付いたとき、

新しい意味が生まれます。

Tsumugiは、その瞬間を支援します。

---

# Product Vision

記録するためではない。

**未来を創るために残す。**

AIは検索をする存在ではありません。

Tsumugiでは、

AIはあなたの人生の**編集者**になります。

過去の経験をつなぎ、

まだ自分でも気付いていない可能性を見つけ、

新しい視点やアイデアを生み出します。

---

# What makes Tsumugi different?

## AIは交換できる。

AIは進化します。

ChatGPT。

Claude。

Gemini。

未来には新しいAIも現れるでしょう。

しかし、

**あなたの人生は交換できません。**

TsumugiはAIに依存せず、

あなたの記憶を中心に設計されています。

---

## 記憶は資産になる

一つひとつの会話は小さくても、

時間をかけて積み重なることで、

人生の知識になります。

価値は保存ではなく、

**つながること**で生まれます。

---

## 静けさの思想

Tsumugiは、

通知やゲーミフィケーションで

毎日使わせようとは考えていません。

必要なときに開き、

必要なときだけ話す。

それでも記憶は育っていきます。

---

# Memory Loop

Tsumugiの中では、

すべての会話が循環します。

```
話す

↓

記憶になる

↓

つながる

↓

気づく

↓

創る

↓

未来の記憶になる
```

この循環が、

あなた自身の思考を少しずつ育てていきます。

---

# Seed

Tsumugiでは、

会話は単なる記録ではありません。

**未来の種**です。

今は意味がなくても、

数か月後、

数年後、

別の経験と結び付いた瞬間に、

新しい価値が生まれることがあります。

その瞬間を、

私たちは「発芽」と呼びます。

---

# Principles

Tsumugiの設計は、次の原則を守ります。

- AIは記憶を所有しない
- データの主役はユーザー
- Local First
- Markdown First
- AI Provider Independent
- Privacy by Default
- Connection over Collection
- Creation over Search
