# Memory Graph P1-E：Connect由来の人物候補の誤採用防止

P1-C の「名前の無い記録の候補」で、Connect のつながりを人物との根拠に使う条件を厳しくする。試験フラグ `?memoryGraph=1` のときだけ使う。OFF のときは従来と同じ。

- Capture・Connect の生成処理・Vault・保存形式・既存の Memory と Connect は変えない。AI 呼び出しは無い。
- Timeline・Synthesis・Retrieval の動作、P1-A〜P1-D の判定は変えない。
- 変えたのは `personContext.ts` の候補の判定と、診断ページの表示だけ。

## 実機で見えた問題（原因）

同僚の人物背景に、本人の趣味の発言「最近レストランの料理っていいなと思うことがある。」が、根拠「Connectのつながり・共通の言葉」で候補として出た。

- Connect は、2つの記録の AI の要約・キーワードだけを AI に比べさせて、つながりを作る（`connect.ts`）。誰の発言か、AI の質問・提案かは見ていない。同じ会話の記録どうしはつながない。
- 候補の判定は、この人の記録のどれかと Connect のつながりがあるだけで「構造上のつながり」とし、軸・強さ・理由は見ていなかった。
- 共通の言葉は、つながった記録ではなく、この人の全記録の考えの言葉から取っていた。「最近」のような時間の言葉も数えていた。

## 判定（`personContext.ts`）

名前の無い記録が Connect でこの人の記録（Capture がこの人を記録したもの）とつながっているとき、つながりごとに次を確かめる：

1. つながった記録に、この人についての本人の発言（P1-D で採用できる文）があるか。
2. その発言と、名前の無い記録の本人の発言に、共通の言葉があるか。共通の言葉は漢字・カタカナの語で、ほかの2人以上の人物について本人が使っている言葉と、時間の言葉（最近・今日・先週・毎日など）・一般的な言葉（自分・一緒・本当など）は数えない。

どちらかを満たさないつながりは根拠にしない。Connect のつながりが根拠になるのは、両方を満たすつながりが1つ以上あるときだけ。その場合も「候補」のままで、この人のことと確定はしない（会話には「候補」として渡し、考え・結論に入るのは決定・願いの文だけ）。

Connect の軸・強さ・理由は根拠に使わない。理由は AI が要約から書いた文で、本人の発言ではない。

同じ会話・同じ話題を根拠とする候補は、P1-C のまま（この人の考えの言葉との共通の言葉）。

## 診断ページ

「名前の無い記録」の各行の下に、その記録とこの人の記録をつなぐ Connect ごとに次を表示する：
- 接続元と接続先の Memory ID、軸、強さ
- 使った／使わない、とその理由
- AI が書いたつながりの理由（「本人の発言ではなく、根拠には使わない」と明記）

## テスト（架空データ、`npm run test:person-context`）

`src/lib/personContextConnect.test.ts`：
1. Connect でつながっているが、人物と無関係な趣味の記録は候補にならない。
2. Connect でつながり、人物についての本人の発言と具体的な言葉（企画）を共有する記録は、候補として残り、確定しない。
3. 別の記録との共通の言葉だけでは採用しない。
4. 時間の言葉・一般的な言葉（最近・先週・今日・一緒）だけでは採用しない。
5. AI の質問が要約に入り、AI のつながりの理由が「一緒に行きたい願い」と書いていても、本人の願いとして扱わない。会話にも渡さない。
6. Connect が無いときの候補は従来と同じ（同じ話題＋共通の言葉は候補、共通の言葉だけは候補にしない）。
7. ほかの人物も出てくる記録では、この人について名指しした文だけを読む。確定していない別名の記録は、確定したときだけ使う。

## 対象外（未対応・未検証）

- 同じ会話・同じ話題を根拠とする候補は、この人の全記録の考えの言葉と比べており、時間・一般的な言葉も数えている（P1-C のまま）。同じ会話・話題は Capture が決めた構造上のつながりで、AI の推測ではないため今回は変えていない。
- P1-D の「この人についての文」の判定（共通の言葉）と、後からの説明の結びつけでも、時間・一般的な言葉を数えている。
- AI の要約（summary）に AI の質問・提案が入っても、コードでは検出していない（Capture のプロンプトの指示だけ）。候補の記録の要約は、候補の結論の理由として読まれることがある。
- 時間・一般的な言葉の一覧は形の規則と少数の語で、すべてを網羅しない。
- 実機データでの効果：未検証。診断ページで、使わなかった Connect と理由を確認できる。
