# MVP Definition

Version: 1.0

---

# Goal

Create a product that users want to open every day.

Not because they have to.

Because it helps them think.

---

# MVP Success

A user should be able to:

1. Talk naturally with AI.

2. Automatically save conversations.

3. Search past memories.

4. Discover related memories.

5. Receive AI reflections based on past conversations.

If these five experiences feel delightful,

the MVP is complete.

---

# Included Features

## AI Chat

- Chat interface
- Streaming response
- Markdown support

---

## Memory

Automatic creation of

- Summary
- Keywords
- Links

Saved locally.

---

## Search

Search by

- Keyword
- Date
- Person
- Theme

---

## Related Memories

Every conversation may show

Related memories

to encourage reflection.

---

## Inspiration

One button.

Purpose:

Generate ideas

from accumulated memories.

---

# Not Included

The following are intentionally excluded.

- Cloud sync
- Social sharing
- Team collaboration
- Notifications
- Calendar
- Gamification
- Avatar customization
- AI voice
- Multiple workspaces

---

# Product Rule

Whenever a new feature is proposed,

ask:

"Does this help users think better?"

If not,

don't build it.

---

# Definition of Done

The MVP is complete when one user says:

"I remembered something important because of Tsumugi."

Not when every planned feature has been implemented.
