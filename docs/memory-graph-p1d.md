# Memory Graph P1-D：人物に無関係な発言の混入防止

P1-A〜P1-C の「会話に渡す人物の背景」で、その人物についての発言かどうかを確かめてから、考え・結論と後からの説明に入れる。試験フラグ `?memoryGraph=1` のときだけ使う。OFF のときは従来と同じ。

- Capture・Vault の保存形式・既存の Memory は変えない。AI 呼び出しは無い。
- Timeline・Synthesis の ON/OFF、人物シート（P0）の表示は変えない。
- 変えたのは `personContext.ts` の採用の判定と、診断ページの表示だけ。

## 実機で見えた問題（原因）

同僚の人物背景に、取引先への提出についての仕事の発言（「急に出せと言われても出せない」「取引先なので微妙に言いづらい」）が「考え」として入った。

- Capture は、同じ会話の中で記録を更新するとき、根拠の引用（evidenceQuotes）と話題の発言（topicEvents）を同じ Memory に追加していく。人物の名前がある Memory に、同じ会話の別の話が入る。
- 背景側は、人物の名前（personMentions）がある Memory で、ほかの人物の名前が無ければ、名前の無い文もすべてその人物についての文として使っていた。

## 採用の判定（`personContext.ts` の `relevanceOf`）

人物の名前がある Memory の本人の文を、次のどれかに当てはまるときだけ、この人についての文とする：

| 根拠 | 条件 |
| --- | --- |
| 人物の発言の引用 | Capture がこの人物についての発言として記録した引用（`personMentions.quote`）の文 |
| 名前 | 文にこの人の名前（確定した別名を含む）がある。ほかの人物も出てくる記録では、ほかの人物の名前が並ばないこと |
| 代名詞 | 「彼女」「その人」などで話していて（ほかの人物が出てこない記録で）、次のどちらか：この人の名前を出した文と同じ引用 ／ この人の発言と同じ発言（話題の発言の時刻が人物の発言の時刻と一致）。または、この人についての発言と共通の言葉がある |
| 同じ発言＋共通の言葉 | この人の名前を出した文と同じ引用、またはこの人の発言と同じ発言で、かつ、この人についての発言と共通の言葉がある |

どれにも当てはまらない文は会話に渡さない。次の場合は採用しない：
- 同じ Memory・同じ話題にあるだけ。
- 同じ発言（同じ時刻）にあるだけ（同じ発言の別の話の可能性）。
- 共通の言葉があるだけ。
- 代名詞があるだけで、誰のことか確かめられない。

共通の言葉は P1-C と同じく、漢字・カタカナの語で、ほかの2人以上の人物の記録で本人が使っている言葉は除く。

予定の分類（P1-C）は記録単位で判断するため、従来の範囲の本人の文を使う（文を会話に渡す経路ではない）。名前の無い記録の候補（P1-C）は変えていない。

## 診断ページ

「背景に入れた理由・入れなかった理由」の考え・結論の各行に、次を表示する：
- 入れた文：「この人の話とした根拠」（名前・人物の発言の引用・代名詞と同じ引用・同じ発言と共通の言葉）。
- 入れなかった文：「この人の話と確かめられないので入れない：（理由）」。

## テスト（架空データ、`npm run test:person-context`）

`src/lib/personContextRelevance.test.ts`：
1. 同じ Memory に人物の話と仕事の話：人物の文は残り、仕事の2文は入らない（理由が診断に出る）。
2. 同じ話題の別の話：話題が同じでも、同じ発言の時刻でも、共通の言葉だけでも入らない。
3. 名前を出した文：残る。
4. 確定した別名：確定したときだけ入る。
5. 名前を出さないが根拠がある文：「彼女」と名前が同じ引用、同じ発言で共通の言葉がある文は残る。代名詞だけの文は入らない。
6. ほかの人物が出てくる記録：この人だけを名指しした文以外は入らない。

P1-A・P1-C のテストの架空データは、Capture の実際の形（人物の発言の引用にその文が入る）に合わせた。期待する結果は変えていない。

## 取りこぼしとのトレードオフ（未検証）

- 名前も代名詞も無く、人物の発言と別の引用・別の時刻にある文は、本当にその人についての文でも入らない。
  - 例：人物の発言の後に、別の引用として「もう諦めることにした」とだけ言った場合。
  - 根拠の引用（evidenceQuotes）には時刻が無いため、同じ発言かどうかは同じ引用の中でしか分からない。
- 「彼女」などの代名詞の文は、同じ引用・同じ発言か共通の言葉があれば入る。ほかの人物が出てこない記録に限るが、記録に出てこない別の人を指していても入る。
- 共通の言葉がひらがなだけの言い換えの場合は、結びつかない。
- 実機データでの効果：未検証。診断ページで、入らなくなった文と理由を確認できる。
