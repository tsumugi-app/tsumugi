# UI / UX Design

Version 1.0

---

# Philosophy

Tsumugi should feel like talking to someone
who quietly remembers your journey.

The interface should disappear.

The memories should remain.

---

# Core Principles

1. No home screen.

2. Start with conversation.

3. Reduce decisions.

4. Reduce typing.

5. Surface memories naturally.

---

# Launch Experience

User opens the app.

Immediately sees:

----------------------------------

こんばんは。

今日はどんな一日でしたか？

----------------------------------

No menus.

No dashboard.

No statistics.

Only conversation.

---

# Conversation Screen

The conversation screen is the center of Tsumugi.

Everything begins here.

Components

- Conversation history
- Message input
- Send button

Optional

- Voice input (future)

---

# Ending a Conversation

Users never press "Save".

Saving happens automatically.

After the conversation,

the Memory Engine creates

- Summary
- Keywords
- Related memories

without user effort.

---

# Remember Moments

Sometimes,

instead of greeting,

the app may show:

"One year ago today..."

or

"You've been thinking about health often recently."

These should feel surprising,

not intrusive.

Frequency should remain low.

---

# Search

Search should feel like remembering,

not filtering.

Users may search by:

- words
- people
- emotions
- ideas
- dates

---

# Reflection

Reflection is different from search.

Search answers

"What happened?"

Reflection answers

"What does this mean?"

---

# Inspiration

The Inspiration button opens Create Mode.

Purpose:

Help users discover ideas

that emerge

from connected memories.

Not random brainstorming.

Always grounded in the user's own experiences.

---

# Empty State

When no memories exist,

encourage conversation.

Never show empty tables.

---

# Notifications

Optional.

Should never pressure users.

Good example:

"Three months ago,

you started learning AI."

Bad example:

"Come back!"

---

# Emotional Design

The app should feel

calm,

quiet,

warm,

thoughtful.

Never addictive.

Never noisy.

Never gamified.

---

# Design Goal

Users should eventually feel:

"I've been talking with Tsumugi for years."

rather than

"I've been using an app."
